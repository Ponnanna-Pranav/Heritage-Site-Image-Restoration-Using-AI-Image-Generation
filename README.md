# Heritage-Site-Image-Restoration-Using-AI-Image-Generation


📌 Project Description

This project focuses on building an intelligent system using computer vision and machine learning to detect and classify objects (such as animals/humans) in real-time. It leverages modern deep learning models like YOLO to provide accurate detection and alert mechanisms.

The system is designed for practical applications such as surveillance, safety monitoring, and intrusion detection. It can be integrated with cameras and notification systems (e.g., Telegram alerts) to provide real-time updates.
